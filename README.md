# CLI Calculator in C++

A simple, menu-driven command-line calculator built with C++. It supports basic arithmetic operations on multiple numbers, along with power, modulus, square root, percentage, average, and absolute value. Features include input validation, error handling, and calculation history.

## How to Run

### Linux

Make sure `g++` is installed. Open a terminal in the project directory and run:

```bash
g++ -std=c++17 -Wall -Wextra calculator_upgraded.cpp -o calculator
./calculator
```

### Windows

Install a C++ compiler such as MinGW-w64 and ensure `g++` is available in your PATH. Open a terminal in the project directory and run:

```bash
g++ -std=c++17 -Wall -Wextra calculator_upgraded.cpp -o calculator.exe
.\calculator.exe
```
